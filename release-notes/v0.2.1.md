Fixes "App not installed" when updating.

Every build used to be signed with a new random key, so Android refused to install updates over an older version. From this version, every release is signed with the same permanent key.

## Install
If you have v0.2.0 or earlier installed, **uninstall Lastmark first**, then download `lastmark.apk` below and open it. This is a one-off. Future updates will install over the top.

This is also the first release build (smaller and faster than the earlier debug builds).
